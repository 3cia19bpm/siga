# SIGA — 3ª CIA / 19º BPM

Interface pública e recursos estáticos do Sistema Integrado de Gestão
Administrativa (SIGA).

## Recursos versionados

- `index.html`: interface web responsiva.
- `manifest.json` e `sw.js`: instalação e funcionamento offline.
- `icon-*.png` e `apple-touch-icon.png`: identidade do aplicativo.
- `brasao-pmce.png` e `brasao-19bpm.png`: brasões institucionais usados no
  acesso e nas marcas-d'água da interface.

Os recursos visuais são mantidos como arquivos PNG para permitir cache,
revisão de alterações e reutilização pelo GitHub Pages e pelo Apps Script.
